    가격지수

  • 지하철역/버스정류장 위치·수
  • 병원/약국·공원·마트/편의점 분포
  • 고속도로 진입로·소음/도로 인접도

  • 역/정류장까지 거리·도보시간
  • 출발지→후보 통근시간

  • 역세권거리, 병원거리, 공원개수

  • 가격/입지 종합 스코어

※ 모든 공공 API 약관을 준수하며, 일부 지표는 내부 가공·결합하여 산출합니다.

설문 항목

필수 질문

질문key설명연결 데이터
최대 예산(구매가) budget_max 총 매입 가능 한도 국토부 실거래가
대출 사용 여부/한도 loan_use, loan_limit LTV·상환능력 고려 ECOS 금리(참조)
선호 지역(시·구·동) pref_region 관심 생활권 제한 법정동코드·좌표
주택 유형 housing_type 아파트/오피스텔/빌라 등 물건 속성
전용면적(㎡) 범위 area_min, area_max 면적 구간 지정 실거래 면적
입주 가능 시기 move_in_deadline 입주 시점 제약 거래일자/잔금

선택/가중치 질문

질문key설명연결 데이터
역까지 거리(도보) 선호 max_station_dist, weight_station_dist 역세권 거리 허용치/가중치 역 좌표·도보시간
통근 시간(출발지) commute_origin, commute_time_max 출발지→후보 통근시간 경로 API
병원 접근성 weight_hospital, max_hospital_dist 병원까지 거리/개수 반영 병원 좌표·거리
마트/편의점/상권 weight_market, weight_convenience 근린 상권 선호 POI 수
학군/학교 밀도 weight_school 초/중/고 밀도·거리 학교 위치·밀도
층 선호(저/중/고) floor_pref 채광/소음/뷰 고려 실거래 층
준공연도(신축 선호) built_year_min 노후도/수선 부담 건축년도
관리비 민감도 maintenance_sensitivity 대단지/시설 대비 면적·시설(추정)
고속도로/큰도로 인접 max_highway_dist, weight_noise 소음 회피 고속도로 거리
주차/EV 충전 need_parking, need_ev 차량 보유 고려 단지 시설(추가 입력)
반려동물 여부 pet_allowed 단지 규정 확인 단지 정보
향/채광(남향 등) orientation_pref 일조 선호 평면·층수(추정)
보안/치안 weight_security CCTV/경비·지역 치안 단지/지역 통계
구매 목적(자가/투자) buy_purpose 수익/거주 가중치 가격지수·유동성
